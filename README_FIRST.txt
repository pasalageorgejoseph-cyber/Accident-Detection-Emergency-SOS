ACCIDENT DETECTION - ANDROID STUDIO PROJECT

IMPORTANT:
Open THIS folder in Android Studio:
  AccidentDetection/

It must contain:
  settings.gradle.kts
  build.gradle.kts
  gradle.properties
  gradle/
  app/

Do NOT open the inner app/ folder as the project root.

The Android application module is:
  :app

After opening:
1. Wait for Gradle Sync to finish.
2. Select the 'app' run configuration.
3. Select your Vivo device.
4. Click Run.

If Android Studio asks to trust the project, choose Trust.
If Gradle Sync shows an error, copy the exact red error and send it.
